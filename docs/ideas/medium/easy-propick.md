# Easy Propick

Remove the existing prospecting pick modes. Replace with 3 new modes:

1. Proximity 
   Just tells you the exact direction to the nearest ore nodes within range, maybe 32 blocks, configurable.
   N, NE, E, SE, E, S, SW, W, NW
   Above, Level, Below

2. Probability
   Same thing but points to the highest spawn probability chunk within range, maybe 16 chunks, configurable.

3. Bore
   Samples all blocks in a 3x3 column below you all the way to mantle, tells you what ores are present, max range configurable.

Each mode can be individually disabled in server mod config.
